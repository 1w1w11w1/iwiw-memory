# 机制证据审计：验证有效 / 竞品存在 / 直觉自创

> 方法：逐机制标注证据等级（实测数字 / 市场先例 / 未验证直觉）；对"自创"机制联网查证先例；
> 查证引用：Codex RFC #8573、context-warp-drive（deterministic folding 社区实现）、REMem（ICLR 2026）、
> Selective Memory Retention（arXiv 2606.29178）、snap-research/locomo（ACL 2024）、dial481/locomo-audit。

## 1. 证据分级总表

| 机制 | 证据等级 | 实测数字 | 市场先例 |
|---|---|---|---|
| FTS5 + jieba + 子串兜底 | **实测有效** | 核心 3/3（含 CJK 兜底断言）、联想 direct 2/2 | FTS/BM25 是行业标配 |
| 同义词表（L1 近义） | **实测有效** | semantic 3/3（去向量后靠它补齐） | 老式 IR 技术，检索系统标配 |
| SessionState 回指（L2） | **实测有效（部分）** | topic 3/3；长对话回指 3/7（42.9%） | 近缘先例：对话状态跟踪（DST）、REMem 情景记忆推理；插件生态无同款 |
| DSC 确定性压缩 | **实测有效（结构）** | 万字触发 5 次、检查点非空、回指不降 | **先例确认**：Codex RFC #8573（生产）+ 社区 context-warp-drive 独立实现 |
| mutation 契约（version/audit/rollback） | **实测有效** | 核心评估断言 version_id/audit_id/changed_rows | 七家中最完整（StrataGate 事件卡最接近） |
| E2E 管道测试 | **已建立** | 基线 3/6（红基线） | graph-memory 20 轮评测、StrataGate LoCoMo 同思路 |
| 去向量化决策本身 | **A/B 实测** | 有向量 10/10 vs 去向量+jieba+同义词+状态 10/10（持平） | mnemon 证明零 API key 可行；meow 证明零原生依赖可行 |

## 2. 凭直觉、市面未直接存在——逐项查证与验证路径

| 机制 | 现状 | 查证结果 | 能否验证 | 验证方式 |
|---|---|---|---|---|
| SessionState 具体形态（n-gram 主题轨迹 + 词面倒排 + 窗口去重） | 在用 | 组件有先例（DST/情景记忆），**该组合自创** | ✅ 部分已验证（42.9%） | **消融实验**：禁用 SessionState 只留 FTS，对比回指命中率下降幅度 |
| 触发词表提取 | 在用 | 市面用 hook 全捕获 + LLM 判断 | ✅ 已验证为**无效**（覆盖 2/10） | 重做后同场景复测（E2E trigger_coverage 由红变绿） |
| pending 事前审批 | 在用 | 与头部共识（对话即记忆）相反 | ❌ 未验证净收益 | 依赖"沉默写入 + 事后审查"替代后，用误写率/用户打断次数对比 |
| 90 天半衰期衰减参数 | 在用（retrieval 加权） | 无 | ⚠️ 拍脑袋参数 | 需长期使用数据；短期标记为可配置假设，不算已验证 |
| 记忆标签（L3 备选） | 未实现 | — | — | 已被 jieba+同义词覆盖，暂不需要 |

## 3. 结论

1. **核心检索/组织/审计机制全部有实测数字背书**，无凭直觉的部分。
2. **两个"自创"机制查证结果**：确定性压缩有生产先例（方向被验证）；SessionState 组合自创但已部分验证（42.9%），待消融实验补完。
3. **一个已证伪机制仍在线上**：触发词表（覆盖 20%）—— 是当前最高优先级修复项（E2E trigger_coverage 红基线已钉死）。
4. **两个未验证假设显式挂账**：pending 审批的净收益、90 天半衰期参数 —— 均需使用数据，不得当作已验证能力对外表述。
