# 记忆编辑策略

本策略用于 GUI 手动编辑、合并、删除和归档长期记忆。

## 编辑

- 保留 frontmatter 中的 `priority`、`type`、`event_date`、`recorded_date`。
- 编辑前显示 diff。
- 保存前备份旧文件到 `memory/.history/`。
- 保存后重建 `MEMORY.md`。

## 合并

- 只有明确属于同一主题时才合并。
- 合并后目标记忆应比两个来源更清晰，而不是简单拼接。
- 来源记忆默认归档，不直接永久删除。

## 删除

- 删除前必须备份。
- 用户明确要求删除时优先执行。
- 如果只是过时，优先归档而不是删除。

## 权重调整

- 不因为一条记忆很长就提升 priority。
- `core` 和 `important` 应保持克制，避免启动上下文膨胀。
