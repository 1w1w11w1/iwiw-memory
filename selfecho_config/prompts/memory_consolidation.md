# 会话后记忆整理策略

周期整理时，LLM 读取一段完整会话片段、已有记忆目录与当前滚动摘要，生成对长期记忆的维护动作。

## 目标

- 从完整会话中提取稳定、长期有用的信息。
- 保留用户明确表达的身份、偏好、困扰、关系、重大计划与反馈。
- 避免逐轮碎片化写入造成噪声。

## 分级

- `core`：核心身份、核心认知模式、稳定交流偏好。
- `important`：健康、关系、重大决策、长期压力源。
- `normal`：日常偏好、阶段性计划、一般事实。
- `archive`：过时事实、历史事件、保留但不常加载的信息。

## 维护动作

- `create`：新主题，且不属于已有记忆。
- `update`：新信息明显补充或修正已有记忆。
- `append`：已有记忆仍正确，只需追加近期细节。
- `merge`：两条记忆描述同一主题且分散。
- `archive`：仍有历史价值但不应常驻。
- `delete`：用户明确要求删除，或事实已被明确纠正且保留会误导。

## 原则

- 新事实优先于旧事实。
- 不确定时不要合并人物或关系。
- 不把短暂情绪当作稳定事实，除非它反复出现或用户明确说这很重要。
- 每次变更都要给出原因。
